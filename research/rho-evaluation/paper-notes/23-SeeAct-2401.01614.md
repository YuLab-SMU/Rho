# GPT-4V(ision) is a Generalist Web Agent, if Grounded

## Question

多模态模型可以理解网页截图，但把语言计划准确 grounding 成 HTML 元素和浏览器动作仍是瓶颈。

## Setting and task

- Actor: 视觉网页 agent
- Task: 在 Mind2Web 离线缓存网站和 live websites 上执行多步 web tasks。
- Environment: 2,000+ tasks、137 websites、31 domains；GPT-4V/Gemini/BLIP-2/LLaVA；Playwright online evaluator。
- Evaluation unit: 浏览器 action step 和整项 task。

## Method

SeeAct 的 action generation + element grounding，比较 attributes、textual choices、image annotation 和 human/oracle grounding。

## Evaluation design

- Comparator: GPT-4、FLAN-T5、不同 grounding method、oracle grounding、offline0/offline1/online。
- Evaluator or ground truth: 离线 element accuracy、operation F1、step success、whole-task success；在线由人类 annotator 监控任务完成。
- Metrics: step success、task SR、online/offline success、grounding gap。

## Results

GPT-4V oracle grounding offline step SR 61.9/65.0/62.1%；Choices 为 39.1/32.7/42.0%。whole-task online SeeActChoice 37.8%，SeeActOracle 51.1%，GPT-4 13.3%。离线与在线存在明显差异。

## Ablations and robustness

grounding methods、GPT-4V/Gemini/LLaVA、cross-task/website/domain、offline tolerance and online monitoring。

## Limitations

oracle grounding 使用人类 annotation；online 任务只能做非登录和低风险操作；网页变化、视觉 grounding 和安全限制。

## Rho relevance

直接证明 offline task score 不能代表真实环境能力。Rho 的实验必须把静态可读证据、实际继续操作和领域结果分别验证。

## Interpretive note

SeeAct 的最大方法学贡献是同时报告 offline 和 online，且把 grounding error 单独拆出来。Rho 也需要把记录/理解错误与科学结果错误分开。
