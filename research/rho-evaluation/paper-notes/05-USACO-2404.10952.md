# Olympiad-Level Code Generation with Large Language Models

## Question

HumanEval 等函数级 benchmark 不能充分检验 grounded、非模板化的算法推理和复杂约束。

## Setting and task

- Actor: 代码生成 agent 与 human tutor
- Task: 解决 307 道 USACO 竞赛题，代码必须通过隐藏测试、时间和内存限制。
- Environment: Bronze/Silver/Gold/Platinum 四级；每题有样例、隐藏测试、官方分析和 Python 参考解。
- Evaluation unit: 编程题和多轮 tutoring episode。

## Method

zero-shot CoT、Reflexion、自我反思、semantic/episodic retrieval 及其组合。另有受限规则的人类互动 tutoring。

## Evaluation design

- Comparator: 不同模型、zero-shot、检索类型、反思以及人类 tutoring。
- Evaluator or ground truth: 隐藏 unit tests、编译和资源限制；human tutoring 只给一般性纠错，不提供具体修复。
- Metrics: Pass@1，分难度 solve rate，人类指导后的 solve rate。

## Results

307 题上 GPT-4 zero-shot Pass@1 8.7%，人类平均约 35.83%；episodic retrieval + Reflexion 将 GPT-4 提升到 20.20%。15 道所有自动方法为 0 的题上，GPT-4 加 tutoring 解出 13/15=86.7%，GPT-3.5 仍为 0。

## Ablations and robustness

反思步数、semantic/episodic retrieval、去除检索内容关键部分、模型和题目发布时间。

## Limitations

human study 只有 15 题；tutor 有题目解法并受规则约束；主要是自动代码结果，科学任务的开放式判断不在范围内。

## Rho relevance

直接证明“结果分数相同”掩盖了模型离正确答案的距离。Rho 的 handoff 评估也需要记录错误类型、恢复提示和对工作状态的理解，而非只记最终完成。

## Interpretive note

USACO 的人类 tutoring 是 Rho 阶段二的一个方法学参考：限制人类只提供可复用的诊断提示，再观察 Agent 是否能把提示转成可执行修复。
