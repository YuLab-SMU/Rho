# Cognitive Architectures for Language Agents

## Question

language agent 方法大量出现，但缺少统一坐标系组织已有方法并指导未来设计。

## Setting and task

- Actor: 语言智能体框架与方法作者
- Task: 回顾和分类 language agent 的记忆、动作和决策结构。
- Environment: 概念框架，配合 ReAct、Reflexion、FireAct、ToT 等 case studies。
- Evaluation unit: agent architecture/component。

## Method

用 working/episodic/semantic/procedural memory、grounding/retrieval/reasoning/learning actions 和 planning/execution decision loop 统一描述。

## Evaluation design

- Comparator: 生产系统、控制流、经典 cognitive architectures 与现有 language agents。
- Evaluator or ground truth: 框架的案例覆盖、分类解释力和 actionable insights，非效果 benchmark。
- Metrics: 无统一 quantitative metric；主要是概念覆盖和设计检查。

## Results

指出 grounding 较成熟，memory 和 decision-making 仍早期；建议先问记忆放置、动作边界和决策机制。

## Ablations and robustness

不适用；论文用 case studies 和不同架构组件比较。

## Limitations

描述性而非预测性；模块粒度主观；难以证伪；不规定数据结构或实现。

## Rho relevance

Rho 可借用 CoALA 做架构定位：工作状态是跨参与者共享的记忆与决策上下文，资源动作和结果动作属于不同 owner。CoALA 本身不能验证 Rho 有效。

## Interpretive note

CoALA 是 Rho 定位的框架参考，不是 Rho 的实验依据。最有用的连接是把“记录、检索、修改、继续”都视为可审计的动作。
