# From Pixels to UI Actions: Learning to Follow Instructions via Graphical User Interfaces

## Question

GUI agent 依赖 DOM/HTML 和任务特定动作，遇到无结构化接口或实现变化时缺少通用性。

## Setting and task

- Actor: pixel-only GUI agent
- Task: 仅凭截图和通用鼠标键盘动作完成 MiniWoB++、WebShop GUI 任务。
- Environment: Chrome/Selenium，截图观察；click、drag、key、scroll 等低层动作；终点 binary/partial reward。
- Evaluation unit: GUI task episode。

## Method

Pix2Struct 预训练视觉编码器+文本解码器，behavioral cloning 和 MCTS/tree search 生成更好轨迹。

## Evaluation design

- Comparator: CC-Net without DOM、BC+RL、无 screenshot pretraining、greedy policy 和 tree search。
- Evaluator or ground truth: 任务终点 reward/score，MiniWoB++ success rate，WebShop task score。
- Metrics: success rate、task score、pretraining gain、tree-search improvement。

## Results

像素预训练将 MiniWoB++ BC score 17.1→66.5，WebShop 1.1→46.7；MiniWoB++ 上超过 human crowdworkers，tree search 进一步提升。WebShop 仍落后 HTML-based agent。

## Ablations and robustness

screenshot pretraining、past frames、greedy vs MCTS、demo conversion、DOM access、MiniWoB++/WebShop。

## Limitations

像素 grounding 仍困难；任务评估主要自动 success；WebShop 结果和真实复杂 UI 泛化有限；人类 crowdworker 参照不等于研究者工作评估。

## Rho relevance

说明共享工作状态的可见界面不能假设底层结构总是可用，也要验证用户对呈现结果的理解。Rho 的实验应覆盖资源结构和视图呈现之间的关系。

## Interpretive note

Pix2Act 把“观察形式”和“动作接口”作为独立变量。Rho 的实验可以借鉴这种因素拆分来隔离视图、记录和操作 owner 的影响。
