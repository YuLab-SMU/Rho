# ReAct: Synergizing Reasoning and Acting in Language Models

## Question

CoT 只有内部推理，容易幻觉；纯行动缺少分解和计划。

## Setting and task

- Actor: 知识问答与决策环境中的 language agent
- Task: HotpotQA、FEVER、ALFWorld 和 WebShop 的知识检索、事实核验和交互决策。
- Environment: Wikipedia API、ALFWorld、WebShop 等；few-shot 轨迹或 zero-shot 格式提示。
- Evaluation unit: 问题或环境 episode。

## Method

把语言 reasoning trace 加入动作空间，形成 Thought-Action-Observation 循环。

## Evaluation design

- Comparator: Standard、CoT、Act-only、ReAct、CoT-SC 和 IL/RL agent。
- Evaluator or ground truth: HotpotQA/FEVER 的 exact/label metrics，ALFWorld/WebShop 的任务成功率和人工轨迹分析。
- Metrics: answer accuracy、FEVER label、ALFWorld/WebShop success、幻觉比例和轨迹可解释性。

## Results

ALFWorld 比 IL/RL 绝对提升约 34%；WebShop 相对基线提升约 10%，ReAct SR 约 40%。成功轨迹中 ReAct 的假阳性约 6%，纯 CoT 约 14%。

## Ablations and robustness

去掉 reasoning、去掉 acting、zero/few-shot、CoT-SC 和不同任务格式。

## Limitations

贪心单路线、缺少前瞻和回溯；示例质量敏感；轨迹上下文增长；提示格式可能被模型破坏。

## Rho relevance

ReAct 把内部 reasoning 和外部 action 都视为可记录的工作步骤。Rho 需要进一步记录谁做了步骤、步骤改变了哪项资源，以及下一个参与者如何解释它。

## Interpretive note

ReAct 的最强评估不是最终分数，而是同一任务中“思考—行动—观察”的轨迹能被复查。Rho 的工作状态记录应保留这种可解释轨迹，但增加人和 Agent 的共同所有权。
