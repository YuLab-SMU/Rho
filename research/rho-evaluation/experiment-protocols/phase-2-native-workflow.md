# Phase 2 native workflow comparison

## Identity

- `protocol_id`: rho-native-workflow-v0
- `claim_ids`: `rho-candidate-001`, `rho-candidate-002`
- `status`: draft

## Claim and mechanism

- `claim`: Rho helps a researcher understand and continue a long-running task compared with the native workflow used for the same task.
- `mechanism`: Shared work-state views and explicit provenance reduce the work needed to reconstruct purpose, actions, results and next steps.

## Unit and population

- `unit`: researcher task or matched Agent run
- `population`: researchers who did not build Rho, or matched Agent runs when the study concerns Agent behavior
- `task`: a research task spanning code, data, result, figure and notes
- `data_and_resources`: the same task, inputs, software versions, permissions and domain checks in both conditions

## Conditions and comparison

- `conditions`: Rho workflow; the participant's native terminal, editor or Notebook workflow
- `comparator`: the workflow the target population already uses for the task
- `carryover_controls`: counterbalanced task order, fresh project state and recorded prior exposure

## Measures and analysis

- `measures`: task completion, explanation of what changed and why, wrong beliefs about state, help requests, recovery effort, time, turns and domain-owned result checks
- `analysis`: select aggregation and statistical tests after the literature review and pilot; report task, participant and condition scope
- `missing_or_partial_runs`: preserve unfinished work and record the point of departure
- `failure_and_recovery`: use a failure that the task owner can observe and classify without relying on the Agent's prose

## Completion

- `stopping_rule`: pilot ends after the literature review fixes population, task, comparison and evidence threshold
- `evidence_threshold`: update the human-use or scientific-quality claim only when its own layer has direct observations
- `limitations`: one task, one domain or one participant group cannot establish general benefit
- `source_locators`: `docs/ROADMAP.md`, `docs/DEVELOPMENT.md`, paper matrix after deep read
