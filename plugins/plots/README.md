# Plots plugin

This ordinary package uses the existing plot presentation.
It reads retained original R output Operations and qualified resources through
public interfaces. One exact R provider owns the history; supported committed
PNG, JPEG and SVG outputs retain native session, input source and resource identity.
Viewing never starts R or re-executes a plot. The view preserves selection, zoom,
pan and follow/history choices independently of the scientific runtime.

Original bytes are bounded and checksum-verified before image URLs are created.
The cache protects selected originals, bounds unprotected bytes and revokes URLs
on disposal. Recent-history scans continue across unrelated view captures in
bounded pages. Earlier history preserves the latest and selected original within
a visible 200-plot limit. Saved choices contain no image bytes or browser URLs.

Open Plot in New View captures its original selected resource and request before
submitting the atomic window action. The comparison uses the same exact Plots and
R instances with a pinned selection. Lost replies retain the original request;
copied state can inspect its Operation but cannot replay it from a different view.
Cooperative closure captures final choices while leaving R and its original work
untouched.

Independent assembly and native PNG acceptance pass in the generic window,
including pinned comparisons, final state capture and retained reads after R release.
Original-file export uses the public container download feature: it captures the
selected original, verifies its retained bytes and requests a browser download
without re-executing R. The control is unavailable in containers lacking that
feature. Native acceptance verifies exact original PNG downloads before and after
R release without another execution. Default scenario integration remains in
progress; this is not the completed replacement for the retiring plot panel.
See the repository's current Status for executed verification.
