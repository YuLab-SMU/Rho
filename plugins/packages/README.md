# Packages plugin

This is the ordinary read-only R Packages view. It uses the approved compact
list, wide inspector and copy-specific source details through public contracts.
An exact configured R provider and its first observed native session own all
reads. Counts, list pages and copy details share a native package observation;
busy or expired observations remain identified rather than replaced implicitly.
Refresh explicitly requests a new observation. Viewing never installs, removes,
loads or attaches packages, changes library paths or tests loadability.

The `packages` view configuration selects `source` (an exact R instance), `help`
(an exact Help instance, or null) and `help_group` (the destination tab group, or
null for its own group). Documentation captures the observed copy, native session,
library and version before querying the window and submitting `windows.open_view`.
It opens Help's topic index for that exact copy. The original navigation request
is saved before submission. Missing acknowledgements retain their request identity;
copied state cannot submit it from another view. Bounded Operation reads can find
an original receipt without opening another view. No R code is available here.

Source and project links use public, gesture-bound external-link cooperation.
Source provenance, delivery repositories and project links remain distinct; a
project link does not establish installation history. The R/library dialog only
shows the retained observation. Environment configuration is a separate plugin;
this package does not embed the retiring settings panel.

Presentation choices are saved through the view owner and cooperatively flushed
before closure. The generic window mounts opened Help views and the native
cross-package acceptance passes. Default scenario composition remains in progress. Independent compilation, component and native-browser evidence are recorded
in the repository's current Status; assembling this package alone does not retire
the fixed workbench.
