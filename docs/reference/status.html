Existing application ​

  • Projects opens selected folders and manages finite source folders. Sources counts and browses Data, Code, Results & figures and Notes in one bounded walk; Files exposes the project/source folders. Current-file previews remain current-file facts.
  • Studio shares one Documents buffer per logical document, with confirmed versions, own undo and concurrent-write detection. An Agent edit beside unsaved text is merged or sent through the Documents hook (record). Tabs/splits/moves retain original layout intent and do not cancel tasks.
  • Agent supports Claude/Codex ACP, retained session identity, settings/model choices, native permission requests, cancellation/unknown outcomes, trash and Markdown conversation export. Reads/reconnect do not replay prompts (ACP, panel).
  • Managed execution retains Core's original request identity, output, stop/repair facts and integrity checks. Native execution remains available without Core (boundary). Completion, integrity, domain checks and model judgments are separate facts. Observing native tools grants no managed guarantee.
  • Project/method-scoped HTTP/SSE and MCP discovery expose selected owner capabilities. Local browser access uses same-origin loopback checks; narrower paired access keeps its project/method scope. Models cannot expand grants or create human decisions.
  • Independent UI extensions contribute optional views over selected capabilities; standalone previews receive no project credentials and start no runtime (authoring).
  • rho-screen-check opens a page at four widths in a real browser, reports what it measures beside a screenshot per width, and changes nothing on the page (record).

Earlier observations remain in the home/project, sidebar/canvas, Graph, Agent page, Agent activity and backend acceptance records, within their original scope.

Scope and follow-up ​

The product target is local WebUI on macOS arm64, Linux x64/arm64 and Windows x64, each installed from one tarball in CI. No cloud/account/team/billing, native shell, automatic runtime download or signed release is included; npm publication of a v* tag published @rho-workspace/rho 0.5.2, 0.5.3 and 0.5.4. From 0.5.2 the person installs the Agent clients; Rho pins their ACP adapters. Release separates source, fixed composition, installation and future signed distribution. Offline evidence is not a workspace restore or executable analysis format. Existing archives keep owner fields and reject older formats that would lose state.

The withdrawn 2026-10-25 frontend guidance and the 2026-10-26 design commission are not requirements or templates for these screens. Current work advances by running real episodes and reviewing their results (Development, Frontend). No independent researcher trial or physical IME observation has yet established ease of use. The workspace's first load made a 404 from agent.activity.capture: the preview asked for a capture of an R script, and the example's paths carried the projects-folder prefix. The preview no longer asks for files capture refuses, and new installations get project-relative paths (record).
