# S6 真人验证：主持稿

**状态：真人未验证。** S6 独立记录人的理解，不阻塞 S7 实现、自动检查、修订或检查后的 main 推送。Agent 和自动浏览器的结果不计为参与者记录。

- 用途：[交互计划](INTERACTION-PLAN.md) S6。让一个没读过[交互模型](INTERACTION-MODEL.md)
  的人看着回放回答第 6 节的五个问题，记录卡在哪里。本文是主持人用的，不给参与者看。
- 完成判据（计划 S6）：五个问题各有至少一次不需要旁人解释就答对的记录；答错的有修订。

## 准备

```bash
npm run prototype:replay      # 然后打开 http://localhost:5173/?session
```

- `?session` 没有底部的 dock：参与者只看到外壳。最底下一行灰字是给主持人的，左边
  在停顿时显示 Paused，右边是步号。第二份轨迹用 `?session&trace=check`。
- 主持人的键：空格播放 / 暂停（播放到下面的停顿点会自己停下），← → 单步，`L` 让
  参与者“离开”再“回来”，`E` 把参与者做过的动作和步号存成 JSON（问题框里输入的
  文字不存）。
- 每个场景前刷新页面，回到第 0 步。
- 不录屏，不截图参与者的屏幕以外的东西；只记下面表格里的答案和动作 JSON。

## 开场白（照读，不加解释）

> 这是一个数据分析工作区。一个 AI Agent 在里面干活，你会看到它干活的过程。我会
> 时不时停下来问你两个问题：此刻你看到了什么，你想做什么。没有标准答案，我想知道
> 的是这个界面哪里让你看不懂。你可以随时点任何东西。

之后不解释界面上的任何元素。参与者问“这是什么”，回答“你觉得是什么？”。

## 三个场景

每个场景都在停顿点问同样两句：“此刻你看到了什么？”“你想做什么？”。把回答原话
记进记录表，再对照“期望看到的”打勾。

### 场景 1：全程跟随（第一份轨迹）

空格开始，不做任何操作，到每个停顿点问。

| 停顿 | 期望看到的（不读给参与者） | 对应第 6 节 |
| --- | --- | --- |
| #10 | Agent 改了 `analysis.R`，存成 v2 | 问 1 |
| #15 | 第 1 次运行完成，4 个文件核验通过 | 问 1 |
| #33 | 第 3 次运行失败了 | 问 1 |
| #36 | 失败的原因是语法错误（`unexpected ')'`） | 问 1 |
| #44 | 又失败了一次，原因不同（`object 'op' not found`） | 问 1 |
| #52 | 第 5 次成功，前面几次收成一排标记 | 问 1 |
| #54 | Agent 把图和效应表摆了出来 | 问 1 |
| #60 | 有了一份回答（`findings.md`）和 5 个事项 | 问 1 |
| #66 | 有人问了一个关于图的问题，被取走了 | 问 3 |

到 #68 结束后追加一问（问 2）：“图里的数是哪次运行、哪个版本的脚本算出来的？”
期望两步内到达 Run 5 和 `analysis.R` v9（图 → Run 5 → v9，或从事项进入）。

### 场景 2：中途开始工作（第一份轨迹）

空格开始，到 #15 停下后请参与者：“打开 effects.csv，选中 B、C 两行，看一会儿。”
然后继续播放，不再提示。

| 停顿 | 期望看到的 | 对应第 6 节 |
| --- | --- | --- |
| #33 | 主区没动；上方出现“Run 3 failed”的条，可以点开 | 问 4 |
| #44 | 两条失败的条；主区仍是 effects.csv | 问 4 |
| #54 | 主区没动；出现一条“Show / Dismiss”的建议 | 问 4 |

在 #54 追加一问（问 3）：“你想就选中的这两行问 Agent 一个问题，你会怎么做？”
期望参与者找到表格上方的问题框，问题落在那两行和那个版本上。

### 场景 3：离开再回来（第一份轨迹）

空格开始，到 #15 停下后说：“你去倒杯水。”按 `L`，单步或播放到 #57 停下（用 ← →
或空格；离开期间不提问），再按 `L` 让参与者回来。

| 时刻 | 期望看到的 | 对应第 6 节 |
| --- | --- | --- |
| 回来时 | 一张摘要：`analysis.R` 改到 v9、`findings.md` 出现、运行一行（Run 5 成功，前面带着 2、3、4 的标记，3、4 是红的）、图多了一个版本、一条布局建议 | 问 5 |

追加一问：“你接下来从哪里接着看？”期望答案指向摘要里的某一行，而不是“从头再看”。

### 可选：第二份轨迹

时间够的话，用 `?session&trace=check` 全程跟随一遍，停顿 #11、#13、#17、#19。
重点问：“Agent 改的是哪个文件，跑的是哪个文件？”期望答出改 `stats.R`、跑
`check.R`。这是交互模型 §5 第 10 条的缺口，答不出来不算参与者的错，记下他们
怎么理解两者的关系。
