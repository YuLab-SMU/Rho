# 高保真真实应用 · 实施计划（H0–H4）

起点：W0–W7 完成，M7 已收紧（a0f9035d）。外壳和交互架构是稳定的，这一轮不改它们。

**状态：** 2026-10-25 用户看过 H2 v2 稿 A/B/C 后批准执行（"能动。然后直接应用到项目。直接同步"）。
授权方式同[工作区计划](WORKSPACE-PLAN.md)第 8 节：在本计划范围内自主实施、验证、提交，检查通过后
fast-forward 推送 main；放宽退出条件或改变终点仍需用户。
这一轮要让人在真实任务里看得清、读得对，而且看起来是一个整体。

目标、证据和顺序都来自 `HIFI-H0-AUDIT.md`：先看真实截图，再画稿，最后写代码。

## 边界

- **不做**：
  - 不重写外壳、交互模型、CSS 全局架构，不引入新的设计框架。
  - 不一次改所有页面。
  - 不加仪表卡片、说明文案、全局步骤条、徽章。
  - 不改事实语义，不新增第二套 UI 状态模型。
- **分层不变**：
  - Shell（Rho）负责空间和焦点；
  - 插件（Rho-plugins）负责领域视觉语言，比如表格的数字、图的显示；
  - 表达规则（live / expression）决定 Agent 的动作如何出现；
  - 数据由所有者（Core / Rho facts）决定。
  - 一处改动只落在它所属的那一层。
- **事实错误另修**：审计 P0-2 是 `execution-facts.ts` 的事实错误，单独提交，带回归测试，不混进视觉改动。

## 原则

前三条来自提案，后三条来自 H0 截图。

1. **一个事实一个主位置。** 运行 id、状态、版本各出现一次，位置就是它发生的地方。
2. **颜色只表示交互含义。** 蓝色 = 当前焦点或 Agent 正在做的事。失败色只给"现在就是失败"的东西；已被取代的失败只保留形状，降为弱色。
3. **用空间关系代替解释文字。** 来源、版本、进行中都由位置、形状和虚实表达，不加说明句。
4. **Artifact 是主角，外壳是完整的工作台。** 三栏加底栏：
   - 左：项目树，带数量；
   - 中：问题作标题，Artifact 卡片放在主区；
   - 右：Claude Code 栏，放当前动作、已声明步骤和 Agent 原文备注，以及你的问题；
   - 底：记录活动的时间线，加 Following 开关。

   外壳不为腾地方而收起。让 Artifact 领先靠的是层级：白卡、留白、弱色。
5. **数字按领域读法显示。** 有效位数统一，指数可见，永不截断量级。
6. **一种字体负责一种工作。** 界面文字用 UI 无衬线；代码、路径和标识符用系统等宽字体，不允许回落到 Courier。

## 工作方式：先稿后码

每一个状态都走同一个循环：

1. **真实截图**：一次性服务、真实任务、三个宽度。H0 已建好脚本，可重复运行。
2. **Paper 稿**：一个真实状态一块画板，宽度 1440、1024、390。数据用截图里的真实数据，不用占位文字，不画概念态。
3. **你看稿**：这是设计参考，不是验收。稿定了再写代码。
4. **最小切片实现**：只改这一个状态需要的部分，按层归属。
5. **稿和实现对照**：同一状态、同一宽度，稿与浏览器截图并排放，差异逐条记录，要么修代码，要么回头改稿。
6. **尺子**：
   - M1–M10、E1–E5，现有验收脚本，单元测试，全部不回退；
   - 新增的量化尺子（见下文）必须通过；
   - 报告写清楚改前、改后，以及哪些测试仍然通过。

## 执行中的决定（2026-10-25）

- **三栏的宽度规则。** ≥1280：rail、项目树、主卡片、右栏 Claude Code 四列都在。768–1279：右栏收进
  底栏的一个按钮，打开时浮在右侧，不挤主区。<768：沿用现有抽屉。项目树在 1024 保留（它是导航，
  不是例行进展）。
- **M2 量的是横带。** 右栏占的是宽度，不压内容的高度，不计入 M2 的高度比例；它受 M1（首个内容单元
  在视口内、没被遮住、字号够）和 M9（不横溢）约束。这是对 M2 适用范围的说明，不是放宽：底栏和
  来源行仍按 10% / 15% 计。
- **来源行留在各自视图里。** 原想合进标题行，但验收要求 Agent 原文和产出者都在视图容器内（S7、
  shell），所以每个视图卡片里保留一行来源；标签只写对象名，运行 id 只在来源行出现一次（R3 按视图算）。
- **768–1023 项目树让位。** 打开布局时项目树收起，回到概览时恢复；当前的 Projects 按钮开关它
  （`aria-expanded`），命令面板仍有 Hide/Show。这样 768 宽的图从 0.38 升到 0.60（M1 要求 ≥0.5）。
- **时间线压缩停顿。** 超过两分钟的停顿只占两分钟的宽度，画成一个断点；运行标记按像素保持 ≥24px
  间距，放不下时只显示最近的几次。
- **Agent 声明的"完成"是中性勾。** 稿 A/C 画的是绿勾；实现用灰色勾，绿色只留给 Rho 核过的事实（E4）。
- **回放键不放。** 回放仍是原型，底栏只放记录活动的时间线、运行标记、Working / Following、
  Step away。

## 风险

- **以稿为准做成重新换皮。** 只做审计里有编号的问题。每条改动都要能对回一个编号。
- **改坏插件领域语言。** 表格和图的改动只在 Rho-plugins 里做，外壳不覆盖插件样式。
- **三栏在 1024 以下放不下。** 右栏和项目树怎么让位，要在 1024 / 390 稿里先定，再写代码。E1–E5 中与导航相关的检查必须仍然通过。
- **Agent 跟随规则。** 审计第 8 条要先对照 `INTERACTION-MODEL` 确认意图，只改表现，不改规则。
