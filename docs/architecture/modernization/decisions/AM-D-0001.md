## Measurement boundary

The checker evaluates tracked and untracked source files under the declared
roots. Generated, dependency, and build-output segments are excluded. Every
size result is advisory: crossing the suggested or attention threshold produces
deterministic status telemetry and never fails validation by itself. Status
JSON reports repository-wide totals and largest files so trends remain visible
without legacy baselines, expiry waves or exception bookkeeping.

No file needs an exception merely to compile, test or integrate. A warning asks
the owning package to inspect cohesion, dependency direction, change frequency
and testability; it does not prescribe splitting. Domain ownership,
reviewability and product behavior remain the design authorities.
