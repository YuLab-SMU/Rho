`rusqlite 0.37.0`. `StoreExecutor::open` runs the unchanged synchronous open,

transfers that exact connection to one dedicated worker. Clone handles submit
serialized repository operations; a deliberately slow call left Tokio timers
responsive and two concurrent calls never overlapped or changed worker thread.

by both the existing synchronous `Store` API and the executor. All eight Tauri
commands covering nine persistence operations use the AppState singleton;
there is no unused abstraction or duplicate SQL path. Tests cover successful
write/read/review, normalization, validation and cross-project rejection with
no partial writes, missing-table failure, cancelled waiter recovery,
unsupported-schema rejection without rewrite, close/reopen durability and A/B
isolation.
