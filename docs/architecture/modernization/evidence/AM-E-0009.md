## Result and review

commands are generated from their existing Rust handlers. Two clean generations
are byte-identical, stale output fails, and every invoke string occurs only in
the generated Profile module. Profile imports `SceneStateV1`, `SurfaceOriginV1`,
and `ResourceBindingV1` from their existing generated owners; the shared adapter
removes the resulting unused recursive dependency declarations as one checked
set and refuses any still-referenced omission.

Rust fixtures cover the complete Profile snapshot, recursive Vibe content,
every request nesting, nullable focus, contract literals, and JavaScript-safe
numeric assumptions. Revision, source-line, and insertion-index fields opt into
TypeScript `number` individually; no global lossy mapping exists. The real
transport and browser mock satisfy one eleven-method `ProfileTransport`, and
`UiProfileExternalStore` now depends only on that facet plus its explicit source
and invalidation shell services.

The frontend gate passed 30 files and 244 tests, five deterministic generator
suites, the 193-command inventory across 24 Rust files, generated assets,
Chrome smoke, and real interactions including rejection recovery, narrow layout,
and Vibe editing at 200%-equivalent geometry. The full Rust workspace passed;
the desktop suite reported 334 passed and six existing opt-in/generator tests
ignored, with the Profile exporter exercised by its dedicated generator suite.

237,001 bytes under the same local gzip measurement: +1,036 raw and +139 gzip
bytes. This is engineering telemetry rather than a fixed development veto, and
no material regression was found.
