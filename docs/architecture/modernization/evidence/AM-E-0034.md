## Result and review

`StoreExecutor`. It reuses the exact Store SQL on the executor's one worker;
callers receive no raw connection. Agent context preview and turn admission now
read history and create the conversation/turn/event through that repository.
The admitted normalized project root then travels explicitly with the turn.

`run_agent_turn` and `serve_desktop_agent` use the repository for conversation
history, plugin-context events, immutable context receipts, protocol envelopes,
turn ownership checks, admitted conversation and Runtime-output reads, wait
events, provider events and terminal success/failure persistence. Committed
Workspace identity is read lock-free for response and terminal metadata. Source
review shows their remaining Workspace lock acquisition is the actual
Workspace tool dispatch; approval-sensitive environment paths retain their
existing Broker/Store ordering.

exclusion. The complete Store matrix passed 179 unit and 36 scenario tests; the
server matrix passed 114 library and one binary test; the desktop matrix passed

ignored. Desktop all-target compilation and the 193-command inventory passed.
