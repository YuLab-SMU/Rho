## Covered failures

duplicate records, illegal state transitions, missing disposition packages,
overdue findings, dependency eligibility, implemented packages retaining high
findings, expanded ownership overlap, undeclared changed paths, new-file hard
limits, the then-current legacy no-growth ceilings, and deterministic status
serialization. AM-D-0001 was later amended during AM-W1-02 because exact
snapshot ceilings obstructed necessary contract metadata; current self-tests
cover advisory review bands and emergency ceilings instead.

omitted ten oversized Rust files. The baseline was remeasured and each omitted
file received the original exact ceiling, `AM-F-0002`, a removal package, and an
expiry wave. The second real run passed with 23 advisory-only 800-line warnings
and no hard-limit violation. AM-W1-02 later retained these baselines but changed
their enforcement to review and emergency bands.
