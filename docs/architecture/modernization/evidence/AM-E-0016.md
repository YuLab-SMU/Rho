## Result and review

`plugin_surface_document` and `plugin_surface_event` now export their complete
command contract from Rust. The generated module owns the recursive Surface
document, exact event kind/status, typed command result, bounded recursive JSON,
and every project, plugin, digest, generation, instance, Surface, Page, Layout,
and document revision already present on the wire. The existing generated
`SurfaceInstanceRequestV1` remains the single owner of the shared target shape.

Two clean generations are byte-identical and a one-byte stale fixture fails.
The Rust serde fixture proves the exact snake-case request and response shapes,
recursive document tags, event status, typed command result, provenance, and
arbitrary nested JSON. Focused frontend tests prove exact Tauri requests,
recursive results, stale rejection propagation, contract-literal validation,
and browser-mock assignability to the narrow `PluginSurfaceTransport`.

The complete Rust workspace matrix passed. The desktop suite reported 341
passed and 13 ignored opt-in/exporter tests. The extension-runtime suites passed
their document bounds, malformed/unknown control, stale route, lifecycle,
discovery, and contract coverage. The full frontend gate passed all twelve
generated binding suites, 193 registered commands across 25 Rust files, 37
files/265 tests, the production build, tracked asset identity, Chrome smoke,
and real interactions including plugin tabs, docking, narrow layout, rejection
recovery, and 200%-equivalent geometry.

The entry bundle moved from 855,131 to 855,732 raw bytes and from 237,740 to
237,885 bytes under an explicit Node zlib level-9 measurement: +601 raw and
+145 gzip bytes. This is engineering telemetry, not a fixed development veto;
review found no material performance regression.

A separate post-test review compared the implementation with the accepted
workspace-plugin Surface contracts. Command names, JSON, trusted declarative
renderer, one-active-call fair queue, cache and teardown behavior, exact stale
rejection, project isolation, and Rust Scene/Surface authority are unchanged.
No raw HTML, DOM, filesystem, network, process, credential, Workspace R, Agent
R, Tauri, grant, lifecycle, Wasm, schema, public-protocol, release, signing,
installation, or publication authority was introduced.

`rho-extension-runtime` now declares the already locked `specta` package as a
direct compile-time contract dependency. `Cargo.lock` changed only that direct
edge; no package version or package bytes changed. This compatibility-preserving
contract migration has no application-version or NEWS impact.
