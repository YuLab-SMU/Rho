## Result and review

The three Store-backed Agent conversation inventory commands are generated from
their existing Rust handlers and Store response owners. Two clean generations
are byte-identical, stale output fails, and every invoke string occurs only in
the generated module. The generator preserves Tauri's `conversationId` argument
casing and the transport retains the existing default limit of 50.

`usize` is deliberately absent from the IPC boundary: current tauri-specta
documentation and an exporter compile check confirmed that command parameters
do not support field-level Specta overrides, while global bigint-to-number
conversion would be lossy. The existing JSON `number` limit is therefore a
`u32` at the handler boundary and is explicitly converted to Store `usize`.
This preserves all frontend calls, defaulting, Store clamping, and query JSON
while removing platform-width ambiguity.

Rust fixtures cover conversation and turn summaries, nullable values, and
JavaScript-safe counters/revisions. The real transport and browser mock satisfy
one three-method `AgentConversationTransport`; unknown stored modes fail at the
facade instead of weakening the existing `ask | plan | act` frontend contract.
Focused Store tests cover persistence, migration, recovery, deletion, pending
approval interaction, query normalization, and two-project isolation.

The frontend gate passed 31 files and 247 tests, six deterministic generator
suites, the 193-command inventory across 25 Rust files, generated assets,
Chrome smoke, and real interactions. The full Rust workspace passed; the
desktop suite reported 335 passed and seven existing opt-in/generator tests
ignored, with this exporter exercised by its dedicated generator suite.

The entry bundle moved from 851,724 to 852,107 raw bytes and from 237,001 to
237,120 bytes under the same local gzip measurement: +383 raw and +119 gzip
bytes. This is engineering telemetry rather than a fixed development veto, and
no material regression was found.

Command names, argument keys, JSON response shapes, query defaults and ordering,
conversation creation, project isolation, Store schema, and mock behavior are
unchanged. No version, NEWS, schema, permission, public protocol, release,
signing, installation, or publication change is required or claimed.
