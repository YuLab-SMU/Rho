## Result and review

`commands/artifacts.rs` now owns the ten Artifact/Plot adapters, their request
and response DTOs, export safety helpers, plot payload pruning and retention
projection. `main.rs` only registers those command paths. The new command
inventory assertion makes that ownership discoverable and rejects either a
missing adapter or accidental reaggregation.

The moved implementations retain exact filesystem extension/collision checks,
PNG validation, CSV/TSV encoding, Workspace dispatch, Store repository calls,
artifact-before-revision ordering, project scoping and error strings. The
History/Artifact generated contract is byte-current and all 193 command names
remain registered in the same order.

Focused Artifact and Plot tests pass, the complete desktop matrix passes 354
tests with 21 explicit ignores, and the all-target check is warning-free. As
diagnostic telemetry only, the composition root moved from 18,370 to 17,718
lines while the new cohesive module is 673 lines; acceptance rests on domain
ownership and contract equivalence, not either count.
