## Result and review

`agent_runtime_status` and `agent_runtime_retry` now return one required-field
IPC view and are generated into a domain-specific TypeScript command/type
module. The existing internal `AgentRuntimeStatus` retains every
`serde(default)` needed to read historical cache data; a separate
serialize-only view prevents those input compatibility defaults from
incorrectly making always-present response fields optional.

The generated factory owns both no-argument command strings. The real
transport and browser mock implement one two-method `AgentRuntimeTransport`,
and workspace preparation invokes the same generated retry method
fire-and-forget before project restoration. Dependency probe failure still
cannot reject Workspace R startup, project restore, or other workbench
surfaces.

Two clean generations are byte-identical and a one-byte stale fixture fails.
The generator test name deliberately avoids the existing generic Runtime
exporter's substring so Cargo filtering cannot select both exporters with one
output environment. Adding the dependency diagnostic source contract to
`rsr:check` also exposed and removed its invocation-cwd dependency; it now
resolves repository files from its own module location.

Rust serialization covers ready/degraded identity, nullable package fields,
Provider-adapter failure, bounded detail/remediation, and the complete required
response shape. Existing classification tests cover missing, incompatible,
namespace/API, process failure, bounds, recovery, and Provider-adapter
isolation. The focused runtime suite passed three tests with its opt-in
exporter ignored. The full Rust workspace passed; the desktop suite reported
338 passed and ten existing opt-in/generator tests ignored, with this exporter
exercised by its dedicated generation suite.

The final frontend gate passed 34 files and 256 tests, all nine deterministic
generator suites, the 193-command inventory across 25 Rust files, production
assets, Chrome smoke, and real interactions. The entry bundle moved from
852,685 to 852,843 raw bytes and, under an explicit Node zlib level-9
measurement, from 237,100 to 237,126 bytes: +158 raw and +26 gzip bytes. These
values are engineering telemetry rather than a fixed development veto; no
material regression was found.

Command identity, no-argument shape, diagnostic JSON fields/defaults,
dependency classifications, remediation, invalidation, retry behavior,
startup ordering, Agent-only fault isolation, Provider/credential/network and
Workspace authority, and user behavior are unchanged. No version, NEWS,
schema, permission, public protocol, release, signing, installation, package
provisioning, or publication change is required or claimed.
