## Result and review

The desktop conversation list/create/delete, turn list/detail, retry source,
approval list/response, clear-history, single-turn cancellation and bulk
interruption paths now await `AgentRepository`. No Agent-owned Tauri adapter in
this set calls `read_store` or executes SQLite on its async request thread.
Repository additions delegate to the existing Store methods for conversation,
turn, approval and environment-request terminal bookkeeping.

The transition gate remains held around conversation mutation, retry admission,
history deletion and cancellation. Active task and file-mutation blockers still
run before destructive conversation/history changes. Approval delivery still
wakes only the exact turn waiter; an absent waiter is persisted as interrupted
with `agent_unavailable`. Single and bulk cancellation still cancel waiters,
abort or interrupt the task, persist approval and environment-request outcomes,
append the terminal event, then finish the turn. Generic active Workspace Run
cancel remains deliberately on the existing Run/Workspace path.

Repository tests cover durable reopen, rejected-write recovery, foreign-project
exclusion, conversation/detail listing, turn enumeration and terminal delete.
The focused desktop Agent matrix passed 76 tests with seven existing generated
or platform opt-ins ignored. The complete desktop matrix passed 347 tests with
21 such tests ignored; all-target compilation and the 193-command inventory
passed.

Review found no SQL, transaction, schema, command, serialized response,
project-scope, approval decision, cancellation outcome, version, NEWS or release
change. Plugin projection and Workspace/environment execution coupling remain
separate work under AM-F-0003.
