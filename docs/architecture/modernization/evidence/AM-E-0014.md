## Result and review

`agent_llm_settings` and `agent_llm_set_context_capacity` now generate one
complete presentation-safe settings contract from Rust. The generated module
owns the no-argument query and exact nested `request` mutation argument. It
includes flattened Provider/model views, capability maps/routes, selected
model, environment metadata, validation state, revisions, context capacity,
and provenance without introducing a credential-value field.

The frontend's former handwritten capacity-only subset is gone. The public
types derive from the full generated wire, and the browser mock now projects
the same complete safe shape with `credential_status=unchecked`. The real and
mock transports implement one two-method `AgentSettingsTransport`; existing UI
consumers continue to read the same fields and preserve the same behavior.

Two clean generations are byte-identical and a one-byte stale fixture fails.
Rust serde fixtures cover flattened profiles, nullable values, capability maps,
routes, credential observations, context provenance, safe revisions/capacities,
and absence of secret material. The dedicated settings serialization suite
passed with its opt-in exporter ignored. The Agent LLM suite passed 49 tests
with the live Keychain smoke ignored, including zero-read settings projection,
credential non-persistence/redaction, V2-to-V3 capacity recovery, revision CAS,
invalid/stale rejection, injected save failure, retry, and reopen behavior.

The full Rust workspace passed; the desktop suite reported 339 passed and
eleven existing opt-in/generator tests ignored, with this exporter exercised by
its dedicated generation suite. The final frontend gate passed 35 files and
259 tests, all ten deterministic generator suites, the 193-command inventory
across 25 Rust files, production assets, Chrome smoke, and real interactions.

The entry bundle moved from 852,843 to 854,242 raw bytes and, under an explicit
Node zlib level-9 measurement, from 237,126 to 237,565 bytes: +1,399 raw and
+439 gzip bytes. The increase is the complete mock presentation shape and
generated narrow transport; it is engineering telemetry rather than a fixed
development veto, and no material regression was found.

Command identity, arguments, JSON fields, flattening, zero-read credential
projection, revision/CAS, validation, mutation failure/recovery, schema,
Provider/model/route and credential authority, and user behavior are
unchanged. No version, NEWS, schema, credential, network, permission, public
protocol, release, signing, installation, provisioning, or publication change
is required or claimed.
