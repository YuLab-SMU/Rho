## Result and review

`list_runs`, `list_artifact_records`, `list_problems`,
`list_plot_artifacts` and `read_plot_artifact` now export their existing Rust
DTOs and exact command arguments. The generic domain panels and Plot preview
consume a narrow generated History read facet; Store project scoping,
retention, provenance, list defaults and preview bounds remain unchanged.

The first generator run correctly rejected the command signatures because
Specta represents Rust `usize` as a forbidden TypeScript bigint. Replacing the
public JSON numbers with narrower Rust integers would have changed the existing
Tauri contract, so the fix adds the serde-transparent `UiIpcUsize`:
deserialization retains the full native `usize` behavior while Specta projects
the JavaScript wire type as `number`. Durable optional `i64`/`u32` revision,
document and source-location values receive explicit number metadata without
changing serde. Two clean generations are byte-identical and a stale file
fails.

The full desktop suite reports 344 passed/18 ignored; the frontend reports 18
generated suites and 193 commands, 42 files/276 tests, production build, Chrome
smoke and real interactions. The entry bundle changed from 857,279 to 857,761
raw bytes and 238,317 to 238,421 gzip level-9 bytes: +482 raw/+104 gzip. This is
telemetry, not a fixed veto. Review found no lockfile, schema, persistence,
permission, execution, filesystem, network, credential, release or user-visible
behavior change. No version or NEWS update is required.
