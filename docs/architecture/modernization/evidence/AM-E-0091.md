## Result and review

Workbench composition now has one React subscription and publishes one deeply
immutable, validated `WorkbenchProjectionV1`. Global generation ordering
rejects late A/B/A responses even after an error state; equal-generation data
conflicts fail explicitly. Initial load, refresh, project switch and mutation
failures no longer masquerade as successful publication. Domain selectors and
mutation methods remain narrow, while all successful mutations observe a newer
same-project complete projection before resolving.

The six legacy stores were removed. Focused coverage proves one underlying
subscription, invalidation coalescing, mixed-project rejection, global A/B/A
ordering, mutation refresh failure/recovery, project switching during mutation,
and dependency on in-flight mutations without a global serialization lock. The
complete UI result is 47 files and 290 tests. Production build, generated
contract/asset identity, Chrome smoke and real interactions also pass.

Complete App verification exposed `AM-F-0098`: initial Console state
compaction could advance `surface_revision` while execution still held the
render-captured CAS target. Execution now waits only for already-running
projection mutations, then derives both Console and Runtime targets from the
latest coherent projection. The original emergence/execution regression passes.
