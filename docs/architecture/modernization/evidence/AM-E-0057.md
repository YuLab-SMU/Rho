## Result and review

Workspace bootstrap and request dispatch now submit every run, kernel event,
environment snapshot, identity, terminal outcome, plot and artifact write to
the application's shared single-connection Store worker. Ark uses its awaited
async event callback, so events are neither buffered nor reordered and a
rejected durable event aborts the execution path instead of allowing a false
successful response.

Workspace broker authorization and revision mutation remain under the same
serialized lane. The active project is captured before execution; environment
approval claims and before/after snapshot positions are unchanged; identity is
durable before the run terminal phase; plot and artifact drafts retain their
original order, provenance and project root. The legacy synchronous Store is
still present only for startup recovery, Agent approval and project-switch
reconciliation, explicitly carried as residual Wave 2 work.

Store verification passes 223 tests, including worker operation rejection,
cancelled waiters, recovery and project isolation. Server verification passes
115 tests, including Workspace lane progress and scientific projections. The
complete desktop matrix passes 352 tests with 21 explicit ignores. The
193-command inventory, schema, IPC, version, NEWS and release behavior are
unchanged.
