## Result and review

Manifest V1–V3 packages without `runtime.abi` resolve explicitly to `core-v2`.
Manifest V4 rejects missing, null, unknown and structurally invalid ABI values
and accepts exactly `core-v2` or `component-v1`; discovery records the declared
ABI without inspecting guest exports or imports.

The schema-version increase does not accidentally move Surface/Check
contribution availability from V3 to V4: contribution gating now uses its own
V3 constant. Existing identity, digest, discovery, contribution and permission
tests remain green (220 extension-runtime, 13 plugin-dev and 71 focused desktop
tests). This evidence establishes only package selection; no
Component engine or executable `component-v1` path is claimed.
