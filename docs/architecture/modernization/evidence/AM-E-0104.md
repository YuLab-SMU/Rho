## Result and review

`PluginGuestHost` is selected only from the already-validated `RuntimeAbi` and
never retries construction through the other parser. Both large concrete hosts
are boxed behind the enum, keeping the facade small without erasing ABI
identity. The facade forwards exact host identity, lifecycle, broker steps,
contribution calls, timeout quarantine and cancellation handles.

`ContributionCallSession` now depends on the narrow `GuestCallHost` trait, so
both ABIs share the same route identity, supplied-handle, deadline, schema and
terminal-result checks. Parity tests execute lifecycle and complete/yield/
resume/cancel flows through both enum variants, reject cross-ABI byte parsing,
exercise the shared contribution session and prove a fault or cancellation in
one project does not change its sibling. Existing concrete core-v2 tests remain
source-compatible. The extension runtime passed 239 tests, plugin authoring 13
tests and the focused desktop plugin boundary 71 tests.
