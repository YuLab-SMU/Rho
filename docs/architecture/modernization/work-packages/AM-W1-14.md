## Boundary

Generate `plugin_surface_document` and `plugin_surface_event` from the existing
Rust requests, recursive `SurfaceDocumentV1`, exact event status/result, and
bounded JSON projection. Reuse `SurfaceInstanceRequestV1` from the already
generated Surface/Studio owner. Real and mock transports implement one narrow
`PluginSurfaceTransport` with unchanged method names and invalidation behavior.

The locked Specta dependency becomes a direct compile-time contract dependency
of `rho-extension-runtime`; it adds no new package version or lockfile graph.
Command names, snake-case JSON, project/plugin/digest/generation/instance and
Resource/Runtime/Page/Layout revisions, one-active-call queueing, cache/teardown,
same-project Artifact validation, and the trusted React renderer remain
unchanged. Manifest, lifecycle, grants, Wasm ABI, broker operations, schema,
raw markup, external authority, and release are outside scope. Size and build
measurements are telemetry; correctness, authority, determinism, recovery, and
renderer safety decide acceptance.
