## Boundary

Move `workspace_plugins.rs` to `workspace_plugins/mod.rs` and move the complete
inline `#[cfg(test)] mod tests` body to `workspace_plugins/tests.rs`. Keep the
same parent module name and `use super::*` visibility so every production and
test path remains unchanged.

Do not extract or alter production items in this package. Do not change Store
access, lock scope, plugin identity, lifecycle transitions, permissions,
recovery, guest runtime behavior, command registration, JSON, schema or error
text. Those changes require later independently reviewable packages.
