## Boundary

Pending ledgers are captured from one worker operation. Filesystem inspection
receives only owned ledger data and no database handle. Derived recovery events
are appended in the same order and with the same partial-failure semantics as
before. Only after both startup and project-switch recovery use that service may
the `Store` field and constructor argument be removed from the Workspace lane.
