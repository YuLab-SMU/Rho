## Boundary

Add project-scoped cancel and latest-active cancel operations to
`RunRepository`, then use them from Console/Run, Render, restart and Agent-turn
control paths.

The repository only decides and persists the existing Run cancellation flag.
Ark session interruption, task abort/join, render state and project transition
ordering remain owned by their current callers.
