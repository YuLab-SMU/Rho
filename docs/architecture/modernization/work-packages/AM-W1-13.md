## Boundary

Generate `apply_agent_file_edit` and `undo_agent_file_edit` from the existing
Rust request and response types. Preserve Tauri's nested `request` argument,
camel-case wire JSON, project-relative containment, exact proposal/event
identity, disk digest and editor-anchor rejection, durable mutation ledger,
project/workspace response identity, project-switch exclusion, and recovery.

The frontend facet keeps its established snake-case business API and performs
one explicit wire normalization from `afterSha256` to `after_sha256`; browser
mock responses implement that same complete normalized contract. New file
operations, approval inheritance, schema changes, external paths, credential or
network authority, release work, and unrelated Agent commands are outside
scope. Numeric and bundle measurements are engineering telemetry; only
contract drift, nondeterminism, authority change, unsafe numeric transport, or
mutation/recovery regression rejects the slice.
