## Acceptance boundary

The command must hold `project_transition_gate` for the complete capture and
must validate the outer project ID against every nested snapshot and its
project revision. `projection_generation` is process-local, positive and
monotonic; it is ordering metadata, not durable scientific or project state.
Existing domain commands remain compatible. This package must not modify Scene,
persist Dockview state, or replace frontend stores.
