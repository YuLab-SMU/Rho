## Boundary

Generate the existing `resource_list`, `resource_resolve`, `resource_read`,
`resource_update_draft`, `resource_save`, `resource_reload`, `resource_rename`,
and `resource_delete` commands. Move the generated `ResourceBindingV1`
declaration from the Surface dependency graph to the owning Resource module and
make Surface import it. Preserve command names, request nesting, nullability,
errors, project/revision rejection, document dirty/stale semantics, filesystem
mutation, recovery, resource-to-Surface reconciliation, and mock behavior.

Profile/Vibe, Agent, Plugin, Project, schema, permission, and filesystem-policy
changes are outside this package.
