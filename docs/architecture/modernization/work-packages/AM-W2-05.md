## Contract

`WorkspaceBrokerLane` owns one private Tokio mutex around
`WorkspaceBrokerState { broker, store }`. Its guard dereferences to that state
for compatibility and republishes the final Broker identity on drop. The lane
exposes a lock-free `identity()` snapshot via ArcSwap. No consumer can access
the mutable state without taking the named lane.

Replace every `Arc<Mutex<CoordinatorRuntime>>` type and constructor in server,
desktop and Workspace plugin code. Workspace dispatch and Broker/Store coupled
mutations continue to hold the lane across exactly the same operations.
Identity-only consumers switch to the committed projection. Existing
project-transition and Agent Workspace admission lanes remain unchanged.

This package does not migrate Agent persistence onto `StoreExecutor`, remove
the legacy Store connection from the Workspace working set, alter revision or
recovery semantics, or resolve AM-F-0003 in full.
