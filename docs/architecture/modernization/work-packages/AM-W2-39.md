## Boundary

Move state/list, explicit open/pick/restore/save, text/viewer read, file
write/create/delete adapters and safe-delete helpers into one Project facade.
`switch_project` remains the sole transition authority in `main.rs`; the facade
only validates/loads input and calls it.

Project root containment, symlink/file checks, content budgets, atomic writes,
revision persistence order, extension viewer validation, stale A/B rejection,
session logging, command names and serialization remain exact. No schema,
watcher, Store transaction, extension scope or public behavior changes.
