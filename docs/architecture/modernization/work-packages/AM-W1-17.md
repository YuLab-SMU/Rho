## Boundary

Generate `check_project_run` and `check_result` from the existing Rust request
and immutable result graph, then compose a narrow `CheckTransport`. Preserve the
exact command names, request envelopes, snapshot/result contract strings,
project and result identity, stale/dirty rejection, bounded retention,
invalidation, rule-pack failure containment and A/B isolation.

Rust remains authoritative for capture, rule execution, validation, storage,
plugin admission and every stale decision. Generated JSON types convey data
only. Local product correctness, authority, deterministic generation, recovery
and isolation decide acceptance; LOC, bundle size and non-local platform status
are telemetry rather than implementation vetoes.
