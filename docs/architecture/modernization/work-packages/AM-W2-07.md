## Contract

Add a cloneable `AgentRepository` backed by the existing `StoreExecutor` and
the existing Store SQL implementation. Pass the admitted normalized
`project_root` explicitly into the Agent runtime. Conversation history, context
receipts, protocol envelopes, turn events, admitted conversation/output reads
and terminal turn updates execute on the Store worker without acquiring
`WorkspaceBrokerLane`.

Only clone the committed Broker identity projection for response and terminal
revision metadata. Actual Workspace tools, environment preview/execution and
approval stale checks retain their current Workspace and transition ordering.
No schema, SQL, project-scoping rule, command, JSON, approval policy or recovery
contract changes.
