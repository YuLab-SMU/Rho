## Acceptance boundary

Move Plugin field/tab/block renderers and `PluginSurfaceView` into one domain
module. Preserve request identity, document revision, mode, render/load failure,
event value/kind mapping, lifecycle status and every visible label exactly.
Plugin permission, grant, guest execution and broker authority remain outside
the renderer. App retains only typed composition wiring.
