## Boundary

Generate the existing `ui_profile_snapshot`, `ui_profile_set_mode`,
`ui_profile_select_scene`, `ui_profile_select_page`, `ui_profile_page_apply`,
`ui_profile_page_export`, `ui_profile_scene_duplicate`,
`ui_profile_scene_save`, `ui_profile_scene_rename`,
`ui_profile_scene_delete`, and `ui_profile_scene_reset` commands. Profile owns
its persistence and recursive Vibe types while importing generated Scene and
Resource declarations from their existing owners. Preserve command names,
request nesting, nullability, errors, project/Profile/Page/Scene revisions,
mutation and export behavior, backup recovery, invalidation, and mock behavior.

Agent, Plugin, Project, schema, permission, filesystem, and release changes are
outside this package. Compiler and size data remain engineering telemetry; only
contract drift, nondeterministic generation, or behavioral regression rejects
this slice.
