## Boundary

Generate `agent_llm_settings` and `agent_llm_set_context_capacity`. Preserve
the exact no-argument query, nested presentation-safe response JSON, flattened
Provider/model profiles, credential-status observations, capacity provenance,
request key, revision/CAS rejection, validation, write-failure recovery, and
browser mock behavior.

Credential values/read/write/delete, Provider discovery/network/testing,
Provider/model/route management, schema migration, package provisioning,
permissions, and release are outside scope. Numeric and bundle measurements are
engineering telemetry; only contract drift, nondeterminism, secret exposure,
zero-read regression, mutation/recovery regression, or behavior change rejects
the slice.
