## Boundary

Make `rust-toolchain.toml` the only current-version authority. The validator
accepts any explicit stable semver pin when the workspace major/minor baseline,
workflow toolchains, host triples and runtime version checks agree. It must
continue rejecting floating channels, mismatches, duplicate legacy lanes,
unlocked commands, authority expansion and non-reproducible workflow state.

This package does not change the current 1.97.0 pin, Cargo graph or CI topology.
