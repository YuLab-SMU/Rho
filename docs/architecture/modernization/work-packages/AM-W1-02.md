## Scope and authoritative shape

This slice migrates the existing Runtime Output/history retrieval vertical:

- `runtime_execution_get`, `runtime_execution_list`;
- `runtime_output_search`, `runtime_output_policy_get`,
  `runtime_output_policy_update`, `runtime_output_page`,
  `runtime_output_reference`, `runtime_output_prune`,
  `runtime_execution_delete`, and `runtime_output_follow`;
- their request, response, page/chunk/search/policy/reference/mutation and Channel
  frame types.

Execution admission remains in the later Runtime domain slice because its
request graph is owned by the broader Surface/Runtime contract. Existing Tauri
command names, snake_case JSON, serde tags, error strings, handler registration,
project/revision authority, persistence, and mock behavior remain unchanged.

## Generator selection gate

The primary candidate is exactly `tauri-specta 2.0.0-rc.25`, with the exact
published dependencies required by that crate (`specta 2.0.0-rc.25`,
`specta-typescript 0.0.12`). Main-branch documentation currently mentions the
next unpublished pair; local registry metadata and compilation are authoritative
for this pinned slice.

Use the existing Tauri handler while a test-only/export lane collects only the
listed commands. Switch to exactly `ts-rs 12.0.1` without further product-code
expansion if any of these correctness or measured engineering failures occurs:

- two clean generations differ;
- generated command names or serde JSON shapes differ from the current fixtures;
- profiling shows an unacceptable build or binary-size regression with no
  bounded mitigation; or
- Channel arguments cannot be represented without a second handwritten DTO.

Old-compiler compatibility and fixed percentage thresholds are observations,
not automatic architecture vetoes. The repository-pinned compiler, exact
lockfile, deterministic output, contract identity, and affected tests are the
acceptance authorities.

## Generated boundary

The generated file is deterministic, carries its generator/version header, and
is the only full DTO/command declaration for this domain. A small handwritten
facet may normalize ergonomic optional arguments, inject `invoke` for tests,
subscribe to existing invalidation events, and refine store-backed string
domains declared in Rust, but it may not repeat record shapes or command names.

Real Tauri and mock transports implement the same `RuntimeOutputTransport`
facet; other application domains no longer need the complete transport merely
to read/follow Runtime Output.

## Acceptance and recovery

- generation twice is byte-identical and the check fails after one-byte drift;
- Rust serialization fixtures match generated TypeScript expectations for
  normal, optional/null, tagged Channel frame, stale/rejection, and mutation
  outcome shapes;
- every listed command is uniquely registered and generated exactly once;
- mock and real facets expose the same methods and request normalization;
- pinned Rust 1.97.0, affected Runtime Output tests, full frontend gate, bounded LOC debt checks,
  generated source identity, and `git diff --check` pass locally;
- removing the generated file and rerunning the documented command restores it;
- no schema, version, NEWS, release, Windows, distribution, or remote-CI claim
  is made by this local slice.
