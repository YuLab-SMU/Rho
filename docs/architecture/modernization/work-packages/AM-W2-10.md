## Boundary

Move the stable request/response/projection/context types to `contracts.rs` and
move `WorkspacePluginDispatcher`, its result, and the concrete Coordinator
implementation to `workspace_dispatch.rs`. Re-export both modules from
`workspace_plugins` so all existing paths remain valid. Give each module
explicit imports; tests import `Future` and `Pin` directly after those names no
longer belong to the parent implementation.

Do not change fields, derives, serde attributes, visibility, command imports,
dispatch payload, execution origin, broker/store borrowing order, errors,
registry state, schema, lock scope or plugin behavior.
