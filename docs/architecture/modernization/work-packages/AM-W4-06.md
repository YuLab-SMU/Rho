## Acceptance boundary

Introduce `PluginGuestHost`, an explicit `CoreV2 | ComponentV1` enum selected
only from the already-validated `RuntimeAbi`. It forwards identity, lifecycle,
broker-step, contribution, timeout and cancellation behavior without erasing the
selected ABI or exposing a dynamic fallback. `component-v1` construction never
tries core parsing and `core-v2` never guesses Component exports.

Introduce the smallest trait needed by `ContributionCallSession` so the exact
same contribution admission, supplied-handle, deadline, schema and terminal
validation runs for either concrete host and for the enum. Existing core host
tests continue to use `WasmPluginHost` directly; no compatibility facade is
deleted.

Parity tests run the same lifecycle and complete/yield/resume/cancel sequence
through both enum variants, assert ABI identity, exact host identity and sibling
isolation, and prove contribution code remains source-compatible with the core
host. This slice does not modify desktop registry state, Manifest routing,
version metadata or NEWS.
