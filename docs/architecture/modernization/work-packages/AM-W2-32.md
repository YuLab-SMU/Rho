## Boundary

Artifact source reads occur after the Workspace lane is acquired. Plot payload
validation and its disk write still precede the Run provenance query; table Ark
execution and its disk write also precede provenance lookup. Artifact records
remain durable before `broker.project_changed()`, and the new identity remains
durable before the response. Retry loads its exact project-owned Run before
eligibility and arguments validation, then dispatches under the same held lane.
