## Acceptance boundary

Lock `dockview-react 8.2.0`. Dockview may own rendering, split/tab/resize and
drag gestures only. Rust Scene remains the durable authority and every accepted
gesture must become an existing `SceneEdit` against the current revision;
`toJSON/fromJSON` must not enter persistence. Project changes and stale edits
must rebuild from the authoritative Scene without cross-project panel reuse.

The adapter must retain recursive containers, stacks, drag/drop, resize,
collapse behavior, keyboard access, narrow/200% geometry and current Surface
lifecycle. If the library cannot meet those product invariants without a second
layout authority or destructive remounting, remove the dependency and keep the
implemented `LegacySceneLayout` adapter; bundle size is diagnostic evidence,
not a standalone veto.
