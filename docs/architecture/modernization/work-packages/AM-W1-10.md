## Boundary

Generate `agent_context_preview`, `run_agent`, `retry_agent_turn`,
`cancel_agent_turn`, and `respond_approval`. Preserve every current flat Tauri
argument key, command name, nullable/default value, error, response JSON field,
event emission, admission rule, context digest, project isolation, cancellation
and approval recovery behavior, and browser mock behavior.

Agent model/provider settings, credentials, runtime diagnostics, conversation
deletion, approval inventory, file mutation, schema, permissions, and release
are outside scope. Numeric and bundle measurements are engineering telemetry;
only contract drift, nondeterminism, or behavior regression rejects the slice.
