## Contract

Extend `AgentRepository` with project-scoped conversation, turn, approval and
terminal-recovery operations that delegate to existing Store methods. Migrate
the desktop Agent commands and cancellation helpers to await that repository.
The project transition gate, active task registry, file-mutation blockers,
pending approval registries and Workspace execution cancellation ordering stay
unchanged.

Do not move generic Run cancellation, plugin projection, environment preview or
actual Workspace dispatch into the Agent repository. No SQL, transaction,
schema, command, JSON, project-scope, approval decision or terminal recovery
semantics may change.
