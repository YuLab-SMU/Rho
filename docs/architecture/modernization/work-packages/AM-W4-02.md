## Acceptance boundary

Manifest V1–V3 packages that omit `runtime.abi` retain the current core-v2 ABI.
Manifest V4 requires exactly `core-v2` or `component-v1`; missing, null,
unknown and shape-invalid values fail parsing/validation before discovery can
activate code. V4 ABI is never inferred from Wasm exports or imports. Preserve
all current identity, digest, discovery, signature, contribution and permission
behavior. This slice adds no Component engine or guest execution path.
