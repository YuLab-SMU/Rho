## Boundary

Add a cloneable `RunRepository` over `StoreExecutor` for list, problems,
detail and compare queries. It normalizes project roots exactly once and calls
the existing Store implementation on the worker connection. Both legacy Tauri
queries and candidate `RunHistoryBrokerFacade` use that repository.

Malformed source request validation remains before repository access; source
handler failures remain fail-closed with no legacy fallback. Audit panic
containment, mutations, cancellation, render reconciliation, retry dispatch
and startup-owned Store work are outside this slice.
