## Boundary

Make Store-backed plugin repository/service code reusable over both owned and
borrowed SQLite connections, and expose a controlled `StoreExecutor` callback
that cannot leak a borrowed Store outside its worker. Add a desktop plugin
service that reads the committed Workspace identity without waiting for the
Workspace lane and builds Agent projection state on that Store worker. Migrate
Agent context preview and turn startup only.

Keep the project-transition gate, active-turn admission, exact active project
root check, Workspace grant identity, projection contents, error behavior and
two-project isolation unchanged. No operation in this package dispatches or
mutates Workspace R.

Plugin command adapters and lifecycle background paths still borrow the legacy
Workspace Store; AM-F-0003 remains open until later bounded packages move those
plugin-only paths and the full concurrency acceptance matrix passes.
