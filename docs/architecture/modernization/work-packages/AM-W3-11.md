## Acceptance boundary

Move ready-state helper requests, default Workbench store/transport and
`WorkbenchApp` to one module. `App.tsx` retains startup preparation, recovery
attention and the top-level transition into Workbench. Preserve default
transport/store identity, every controller lifetime, project switch ordering,
projection subscription, callback, DOM/accessibility output and test assertion.
This package establishes ownership only; later packages may split Workbench
responsibilities without coupling them back to startup.
