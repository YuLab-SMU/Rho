## Boundary

Replace LOC and planned-wave failures with deterministic telemetry. Let bounded
child packages inside an already authorized active program advance after their
declared dependencies and ownership checks without another human waiting point.
Run focused and changed-boundary checks per slice; run broad matrices at the
integration/wave boundary or when the risk actually spans them. Require an
independent review only for safety-, data-, authority-, public-contract- or
release-significant changes.

Hard failures remain for malformed or dishonest governance state, active path
collisions, known failing relevant checks, data/project isolation, authority and
security expansion, serialized/public contract drift, non-deterministic
generation, unrecoverable mutation and release-specific acceptance. A metric
may trigger investigation and an engineering decision, but cannot select an
inferior implementation merely by crossing a fixed number.
