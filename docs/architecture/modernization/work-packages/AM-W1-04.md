## Scope

Generate the existing contracts for `runtime_list`, `runtime_create`,
`runtime_interrupt`, `runtime_restart`, `runtime_stop`, and
`runtime_execution_start`. The domain facet owns only these methods. Runtime
Output remains in its already-generated facet. `runtime_attach/detach` return the
complete Surface snapshot and therefore move with Surface/Studio rather than
forcing that graph into this slice; Resource/Profile, Agent, Plugin, and Project
also remain later verticals.

The slice preserves all current command names, request nesting, nullability,
snake-case JSON, errors, revisions, project switching, execution admission,
Workspace lane, Store, and mock behavior. Rust continues to decide identity,
stale rejection, lifecycle, generation, cancellation, and project isolation.

## Acceptance

- generation is byte-identical twice and stale checked-in output fails;
- Rust serialization fixtures cover registry, create/interrupt, restart/stop,
  execution admission, optional source context, and errors;
- every scoped invoke string exists only in generated output;
- real and mock implementations satisfy one narrow `RuntimeTransport` facet;
- Runtime consumers no longer require the full transport where the narrow facet
  and explicitly named shell services suffice;
- focused success, rejection/stale, cancellation, recovery, A/B isolation,
  complete affected Rust/frontend gates, bounded LOC checks, generated-asset
  identity, ownership overlap, and diff checks pass.

No schema, permission, credential, public protocol, version, NEWS, release,
packaging, signing, installation, publication, or network authority is added.
