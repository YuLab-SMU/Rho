## Boundary

`bootstrap_bridge`, `dispatch_workspace_request*` and environment snapshot
capture receive the application's shared `StoreExecutor`. Each SQLite phase is
an awaited service operation and the Ark callback awaits event persistence in
arrival order. No run terminal state may be written before its required
identity/snapshot/result facts exist, and no successful response may be
published after a failed durable phase.

The Workspace broker mutex still serializes Ark and revision authority. The
legacy `Store` remains temporarily available only to startup recovery, Agent
approval and project-switch reconciliation paths outside this package; its
removal is a subsequent checkpoint, not hidden scope here.
