over `StoreExecutor`. Migrate the Environment panel queries, pending lookup and
Agent-channel-not-delivered cancellation to it.

`respond_environment_operation` continue using the dedicated environment
workflow in `WorkspaceBrokerLane`, because they execute R and couple durable
request state to Broker identity.
