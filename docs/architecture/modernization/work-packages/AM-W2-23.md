## Boundary

Add `ProjectTransitionRepository` over `StoreExecutor`. One snapshot operation
returns active project root, latest active Run, waiting Agent approvals and the
highest-priority Environment request set. Separate active-root read/write
operations support switch preparation, commit and rollback.

The caller retains in-memory Runtime/Render/Agent/file-mutation blockers and
their priority. `ProjectTransitionGate`, Workspace project-root dispatch,
extension candidates, watcher replacement, last-opened persistence and every
existing failure-injection step remain unchanged.
