## Acceptance boundary

Move the complete Agent Surface implementation out of `App.tsx` without
changing transport calls, Agent approval/file-mutation authority, persisted
view-state shape, Runtime-output context, project isolation, visible copy or
test expectations. `App.tsx` retains only composition and callback wiring. Any
behavior correction discovered during extraction becomes a separate finding
and package rather than being hidden in the mechanical move.
