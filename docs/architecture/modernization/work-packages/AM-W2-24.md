## Boundary

Move interrupted-execution reconciliation; Runtime execution get/list/search;
output page/follow; Agent context range reads; policy get/update; prune/delete;
and UI active Run projection to asynchronous repositories.

Runtime execution admission and the supervised output writer remain unchanged
in this package because the synchronous Kernel callback currently supplies
streaming backpressure. They require a separate producer/consumer design and
failure matrix rather than a mechanical query migration.
