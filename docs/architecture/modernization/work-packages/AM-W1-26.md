## Boundary

Derive the `app_info` response from Rust and expose it through the existing
Kernel transport as a shell-level read. Preserve every existing field, release
channel spelling, runtime optionality and Help formatting. The browser mock
implements the same narrow method without changing its existing Help fixtures.

The boundary ratchet parses every non-generated production transport source
with the repository's pinned TypeScript parser. It rejects direct calls whose
callee is `invoke`, including property access and dynamic arguments; passing the
invoke capability into a generated command factory remains valid. Product
correctness, deterministic generation and contract parity decide acceptance;
LOC and bundle measurements are telemetry.
