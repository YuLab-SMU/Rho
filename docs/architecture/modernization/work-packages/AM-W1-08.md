## Boundary

Generate the existing `list_agent_conversations`,
`create_agent_conversation`, and `list_agent_turns` commands from their
Store-owned response types. Preserve command names, camel-case argument keys,
nullable/default limits and conversation filter, ordering, project isolation,
new-conversation mutation, errors, and mock behavior.

Turn detail, run/retry/cancel, context planning, approvals, LLM settings and
credentials, runtime diagnostics, Agent file mutation, schema, permission, and
release changes are outside this package. Numeric and bundle size data remain
engineering telemetry; contract drift, nondeterministic generation, or behavior
regression rejects the slice.
