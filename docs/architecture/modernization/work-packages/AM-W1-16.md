## Boundary

Generate `ui_kernel_snapshot` and `ui_set_selection` from the existing Rust
contract graph and compose a narrow `KernelTransport`. Preserve exact project,
snapshot, activation, selection and broker revisions, snapshot caching,
transactional selection rollback, plugin-command omission/bounds, invalidation,
health and availability semantics, and A/B/A isolation.

Rust remains authoritative for every projection, validation, stale rejection,
command availability and execution admission. Generated JSON types convey data
only and add no generic execution route or plugin/broker authority. Size and
build measurements are telemetry; correctness, authority, determinism,
transactional recovery and isolation decide acceptance.
