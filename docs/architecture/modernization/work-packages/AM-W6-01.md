duplication, bundle output, lock scope and generated freshness. Cohesive large
modules and bundle trends remain telemetry; only authority coupling, duplicate

checked-in candidate. Record Windows, installed-app and release checks as
unrun—not passed—when unavailable or unauthorized. Promote deterministic local
checks into the ordinary gate where they detect a real regression without
forcing unrelated packages or release ceremony into every feature slice.

gate is true.
