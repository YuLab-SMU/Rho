## Boundary

Add an `AuditRepository` over `StoreExecutor`. Its submitted operation wraps
the existing `Store::audit_reproducibility` call in `catch_unwind`; a domain
panic becomes the existing stable retry message before it can escape the
worker, while connection transport failure remains a distinct typed error.

The Tauri handler continues to parse the same four scope forms before calling
the repository and uses `AuditLimits::default()`. No audit rule, traversal,
query, limit or response type changes.
