## Boundary

Move the exact existing method groups into `activation.rs`, `upgrade.rs`,
`lifecycle.rs`, `permissions.rs`, and `runtime_calls.rs`. Each child adds an
inherent implementation on the existing private registry and imports the
parent's private implementation seam. The parent retains registry/state types,
free helpers and facade module registration.

Keep `issue_workspace_object_references` through crash persistence together in
`runtime_calls.rs` so private admission/cancellation/crash helpers do not gain
wider visibility merely to satisfy a file-size diagnostic. Do not change any
method body, public or crate-visible signature, lock/Store ordering, status,
error, schema, JSON, command, lifecycle, permission, broker or recovery
behavior. The existing test-only `invoke_plugin_with_hook` seam may become
`pub(super)` because its regression callers are now a sibling child module;
that visibility remains contained by the private `workspace_plugins` facade.
