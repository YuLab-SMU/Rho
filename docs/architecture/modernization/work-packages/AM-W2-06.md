## Contract

Keep `Store::open`, migration, schema assertion and migration outcome ownership
on the default owned Store. Generalize repository methods over a connection
holder that dereferences to `rusqlite::Connection`, and let `StoreExecutor`
construct a short-lived borrowed Store session only inside its dedicated
worker callback.

The default `Store` name and all current callers remain source compatible. No
SQL statement, transaction boundary, normalization rule, schema version,
public protocol or serialized response may change in this package. Agent and
plugin call-site migration is deliberately deferred to following concurrency
packages so this mechanical seam can be reviewed and reverted independently.
