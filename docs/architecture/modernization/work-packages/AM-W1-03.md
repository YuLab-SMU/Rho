## Contract

Rho uses one exact, repository-pinned Rust toolchain for normal development and
integration. The workspace `rust-version` follows that pin as a build baseline,
not as a long-lived promise to support old compilers. Advancing the pin is a
normal, atomic dependency/tooling change when it improves implementation quality.

The retained hard gates protect reproducibility, serialization and public
contract identity, security/authority boundaries, deterministic generation,
tests, and recoverability. Old compiler compatibility, arbitrary percentage
budgets, and duplicate release packaging in ordinary development CI are
diagnostic signals unless an active release contract explicitly promotes one
to a candidate acceptance limit.

## Acceptance

- workspace metadata and `rust-toolchain.toml` agree on Rust 1.97;
- Draft and integration Rust jobs select exact 1.97.0 target toolchains;
- the integration matrix has one source leg per supported development OS and no
  duplicate old-compiler or installed-package leg;
- the exact locked tauri-specta graph compiles on the pinned toolchain;
- deterministic contract self-tests reject toolchain drift, missing member
  inheritance, unlocked commands, matrix loss, and reintroduced legacy legs;
- Runtime Output package AM-W1-02 resumes immediately after this package closes.
