domain module. Preserve all Resource target/revision arguments, view-state
persistence, save/reload/rename/delete recovery, rendered markup sanitization,
focus behavior and Source execution routing exactly. App retains resource
callback construction and passes it through typed props. No visible behavior,
version or NEWS change belongs to this package.
