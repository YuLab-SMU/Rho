## Boundary

Run boundary teardown, reconciliation, heartbeat maintenance and Agent plugin
contribution persistence through the application's shared `StoreExecutor`.
Use the last fully committed Workspace identity without acquiring
`WorkspaceBrokerLane` for plugin-only work.

If recovery changes project files, acquire `WorkspaceBrokerLane` only to call
`project_changed` and persist the resulting authoritative identity, release it,
then rerun reconciliation on the Store worker with that fresh identity. Keep
the existing project-transition gate at callers and preserve diagnostics,
recovery reports, permission/grant ordering, guest execution and project
isolation.
