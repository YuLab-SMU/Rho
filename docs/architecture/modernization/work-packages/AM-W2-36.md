## Boundary

Move the Evidence claim-create DTO, DOI resolution adapter, source-range
snapshot helper, Evidence entry/claim commands and their Store-worker calls
into one domain module. The eight-second Crossref timeout, null-on-lookup
failure behavior, project-path containment, editable-file budget, digest and
excerpt rules, project scoping and serialized responses remain exact.

The repository implementation, schema, Store executor, source files and command
registration order do not change. No new network or filesystem authority is
introduced.
