## Boundary

Move AppInfo DTO/handler, native updater state/check/install, product URL and
bundled-license handlers plus their focused pure tests into `shell.rs`. Main
continues to construct the updater state and register the exact same five
commands in the exact same order. The Kernel exporter references the moved
`app_info` function and must regenerate byte-for-byte identically.

This package changes no response, error text, update endpoint, timeout,
shutdown/restart sequence, filesystem validation, platform command, schema,
dependency, Store access, lock scope or public behavior. Concurrency changes
belong to a later package after this mechanical boundary passes.
