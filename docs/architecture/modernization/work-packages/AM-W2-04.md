## Contract

Add one cloneable asynchronous Store handle backed by one
`tokio-rusqlite` worker per application database. Initialization must run the
existing `Store::open` path before transferring its configured connection, so
schema migration, backup/rejection, WAL, foreign keys and busy timeout remain
unchanged. Runtime calls execute only on the connection worker.

Extract the Evidence SQL implementation into connection-scoped repository
functions shared by synchronous `Store` compatibility methods and the async
executor. Migrate create/list/get/delete entries and create/list/get/review/
delete claims together; partial dual implementations are forbidden. Desktop
adapters retain their current command names, request/response shapes, source
snapshot validation and project normalization.

This slice does not remove `CoordinatorRuntime.store`, migrate another durable
domain, alter schema, or claim that the global Coordinator mutex is gone.
