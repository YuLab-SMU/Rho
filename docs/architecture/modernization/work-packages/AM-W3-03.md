## Acceptance boundary

React subscribes exactly once. The store publishes only a complete validated
projection and orders every response by the process-global projection
generation, including A/B/A switching. Domain mutation facades remain narrow,
but after a successful mutation they must refresh and publish the complete
projection for the admitted project before resolving. Refresh failure and a
project switch during mutation are explicit failures, not partial publication.

This package removes the six previous external store implementations. It does
not delete compatible Tauri domain commands, change Scene/revision authority,
or introduce Dockview.
