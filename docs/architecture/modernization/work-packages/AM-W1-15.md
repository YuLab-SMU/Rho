## Boundary

Generate `project_open`, `project_pick_directory`, and
`project_restore_session` from the existing Rust `ProjectRestoreResponse`
graph. The narrow `ProjectTransport` exposes exact-path and picker operations;
startup composition uses the same generated restore command. The browser mock
keeps implementing the public project facet.

Rust remains the only owner of path normalization, native picker cancellation,
active-operation blockers, atomic project commit, durable last-opened project,
watcher and Workspace synchronization, previous-project recovery, project
identity, and restart requirement. No new state, persistence, command, retry,
filesystem authority, UI behavior, schema, or release action is in scope.
Unknown generated response statuses fail closed at the frontend adapter rather
than being treated as readiness. Size and build measurements remain telemetry;
contract, authority, determinism, negative/recovery behavior, and project
isolation decide acceptance.
