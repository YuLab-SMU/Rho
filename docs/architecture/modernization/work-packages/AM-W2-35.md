## Boundary

Move plot/artifact request DTOs, export and projection helpers, ten command
adapters, plot payload pruning and project retention projection into one
domain-owned module. The module continues to call the existing
`ArtifactRepository`, `RunRepository`, Workspace broker lane and identity
persistence service in the exact current order.

`main.rs` retains only composition and registration. Project skills, Evidence,
Run retry, Render recovery and every repository implementation remain in their
current owners. No command name/order, serde shape, error, filesystem policy,
revision mutation, schema or public behavior may change.
