## Acceptance boundary

Move the existing recursive Scene renderer, stack keyboard/pointer behavior,
adaptive collapse, resize and inspector outline into one isolated module. Keep
the rendered DOM, accessibility semantics and emitted `SceneEdit` values
unchanged. This package does not add Dockview, change layout persistence, alter
CAS behavior, or resolve `AM-F-0007`; it creates the controlled adapter boundary
used by the following evaluation package.
