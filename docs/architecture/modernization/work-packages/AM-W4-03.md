## Acceptance boundary

Keep Wasmtime exactly at `38.0.4` and explicitly enable its `component-model`
feature. Define package `rho:plugin@1.0.0` with a world named `plugin` that
exports typed lifecycle (`activate`, `echo`, `heartbeat`, `quiesce`, `dispose`)
and guest-call (`begin`, `resume`, `cancel`) interfaces. Guest call transitions
use a typed `guest-step` variant carrying broker-request, completion or stable
guest-error records; JSON is restricted to the operation argument/result value,
not the step envelope.

The world declares no imports. Admission uses a fresh per-component Engine with
the same fuel, epoch and disabled-proposal configuration as the core host,
enables Component Model explicitly, applies the existing four-MiB binary bound,
rejects malformed/core binaries, and rejects every component-level import
before a Store or guest code can run. WIT-generated bindings must compile, but
this slice does not instantiate or select a component host from desktop code.
Core ABI V2 behavior and tests remain unchanged.

Typed lifecycle execution, StoreLimits enforcement during calls, cancellation,
broker grant replay, quarantine/recovery and two-project equivalence remain
acceptance work under `AM-F-0006`; this package must not claim them early.
