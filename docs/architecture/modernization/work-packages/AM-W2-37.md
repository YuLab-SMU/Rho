## Boundary

Move preview, request list/get, installed and lockfile inventory, and approval
decision adapters plus their DTOs and lockfile limit helper into one module.
Direct UI requests retain their dedicated Environment request table and dialog;
Agent requests retain their separate waiter registry. Only real R operations
acquire the Workspace broker lane.

Project-root normalization, limit bounds, approval values, interruption
recovery, Store operation order, command names, serialization and errors remain
exact. No schema, R bridge, frontend mock or public behavior changes.
