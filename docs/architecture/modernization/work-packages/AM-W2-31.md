## Boundary

Add one internal async helper that saves an owned `WorkspaceIdentity` through
the shared executor. Call it only after `broker.project_changed()` and before
the existing response, Agent terminal event or refreshed plugin context is
published. The Workspace lane remains held during this commit so competing Ark
or revision mutations cannot overtake it.
