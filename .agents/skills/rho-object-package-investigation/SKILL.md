---
name: rho-object-package-investigation
description: Investigate R objects and installed package copies through Rho when analysis requires data structure, later values, package interfaces, provenance, or help evidence.
---

Let the question determine the depth of inspection. Object directory pages locate bindings; object observations identify supported read methods. Preserve the observation reference while reading later values, table rows or columns, and nested lists. R indices start at one. Duplicate child names require numeric indices; object paths are structured data, not R expressions.

On an instance-aware Host, bind each live read to `workspace_instance_id` as well as its native observation. Equal names in Main and Scratch do not refer to the same object. Switching a view does not transfer objects or package observations. A restored object has a new native observation; do not reuse references from the process that originally saved it.

Treat shortened strings as incomplete evidence. Their continuation fields allow the remaining text to be read from the same observation. Keep special values such as NA, NaN, and infinities distinct. Known classes expose underlying values and attributes; unsupported objects remain metadata. Investigative queries must not force promises, active bindings, or user formatting methods.

Package names alone do not identify installed code. Compare the relevant copies' versions, library paths, recorded sources, and loaded identities. Static package indexes expose declarations, topics, and aliases without loading a namespace. Conditional declarations and export patterns can remain unresolved; absence of a resolved export is not proof that a function is unavailable.

Help is an explicit operation that renders a selected document once. Continue reading its retained text artifact, keeping the selected copy and digest. Viewing help does not authorize running examples or installing packages.

If execution or content change invalidates an observation, reopen it and reconsider any combined result. Do not concatenate old and new pages as one unchanged dataset.
